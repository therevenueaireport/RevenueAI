# Positioning gate

Distinctive assets make a brand retrievable. Positioning makes it worth retrieving.
An asset built on vague positioning does not fix the vagueness. It makes the vagueness
easier to recall. That is the worst outcome in the system: famously generic. This gate
stops that before it happens.

Run this before any asset is built. Pass, and route to [[brand-manager]] to audit and
build. Fail, and the honest answer is that no color, mascot, or sound will help yet.
Fix positioning first.

## The three questions

Positioning is sharp enough to build on only when all three have a concrete,
defensible answer. Vague answers fail the gate.

1. **Who is it for?** A specific segment, not "companies" or "GTM teams". Named
   enough that a member would recognize themselves.
2. **What do you do that is different?** Differentiation is solving a specific problem
   that the alternatives leave unsolved for that segment. Not a feature list. Not
   "better and faster". A struggle the segment actually feels that rivals ignore.
3. **Why does it matter?** The stakes for that segment if the struggle stays
   unsolved. If nothing changes for them, there is nothing worth retrieving.

## How to test the answers

- **Swap test.** Put three named competitors' names on the positioning statement.
  If it still reads true for them, it is not differentiated. Fail.
- **Struggle test.** Name the specific, ignored struggle the segment cares about. If
  the "difference" does not map to a real struggle, it is difference for its own sake.
  Fail.
- **So-what test.** State the consequence of not solving it. If the answer is soft,
  the positioning is not worth an asset yet. Fail.

Being different for the sake of being different fails all three. Differentiation must
attach to an ignored struggle the segment actually cares about.

## On pass

Positioning is worth retrieving. Hand off to [[brand-manager]] to run the 0-24 audit
and pick the open asset. State the confirmed segment, difference, and stakes in one
short paragraph so the asset skills can point every asset at something real.

## On fail

Say it plainly and without padding. Name which of the three questions failed and why.
Do not soften it into a brand exercise. The next work is positioning, not design.
Offer to sharpen the segment, the differentiation, or the stakes. Building assets now
would only make the current vagueness more memorable.

## The one-line rule this gate enforces

Positioning, then one open asset, developed with intensity, held everywhere. In that
order. This gate owns the first word.

Keep output spartan and direct. No em dashes.
