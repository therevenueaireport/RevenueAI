# Distinctive asset: product UI motif

A signature inside the product. The software equivalent of packaging. A recurring
in-product element so distinct that a screenshot names the brand with the name
removed. Meaning-free: it is a recognition cue, not a feature claim.

Reference points, all fictional: an issue tracker whose half-filled status rings sit
on every row, so any screenshot of a backlog names it; a cloud-security platform that
draws each threat as one glowing amber route through a grey graph; a personalization
tool whose editor shows every web page as a stack of index cards. The product is where
buyers spend the most time, so a signature there compounds fastest with users.

## Scoring, 0 to 3

- **0 Absent.** No signature inside the product.
- **1 Category default.** A generic interface any competitor's product also shows.
  Default component library, no signature move.
- **2 Distinctive in category.** A signature inside the product recognizable to
  category insiders.
- **3 Out of context.** A UI motif recognizable in a screenshot anywhere, with no name.

## The category-default trap

A 1 is an off-the-shelf component library styled by no one, the same dashboard shell
every rival ships. If the product screenshot could be any competitor, it is a 1.

## No single product? Use the stand-in surface

For a brand whose "product" is content, education, or a service (a community, a course,
a report, a newsletter), the packaging equivalent is the signature interface of that
work: a recurring slide system, a report layout, a course-module frame, a repeatable
diagram style. Score and build that as the motif.

## Moving up the ladder

- **1 to 2:** Design one signature move (an interaction, a recurring layout, a
  distinctive control or view) and repeat it across the product and every marketing
  screenshot.
- **2 to 3:** Hold that motif until a bare screenshot names the brand out of context.

## Build playbook

1. Pick one signature element: a control, a view, a layout, an interaction pattern, a
   recurring visual inside the product or its stand-in surface.
2. Make it distinctive and consistent, not decorative. It should be the thing users
   describe when they describe using the product.
3. Put the same motif into every marketing screenshot, demo, and explainer so it
   travels beyond current users.
4. Protect it through redesigns. A motif only pays off if it survives.

## Hold it across the surface

Product itself, marketing screenshots, demo videos, docs, onboarding, sales deck
product shots, launch graphics. Same motif, on and off the product.

## Anti-patterns

- A default component library with no signature.
- A signature move that never appears outside the app, so no prospect ever meets it.
- Redesigning the motif away every product refresh.
