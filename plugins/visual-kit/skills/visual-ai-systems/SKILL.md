# Visual AI & Technology

Make abstract AI concrete **without robot clip-art**. These turn "we use AI" into a structure someone can reason about, argue with, and govern.

## Claim -> visual

| The claim is about... | Use |
|---|---|
| Layers needed for AI outcomes | AI capability stack |
| Organizational progression | AI maturity model (experimenting -> AI-native) |
| Which use cases first | use-case portfolio (impact x feasibility, risk as bubble size) |
| Roles & handoffs among agents | agent architecture; agent swarm |
| Who does what | human-AI division-of-labor map; augmentation-vs-automation spectrum |
| Embedded assistance | embedded-assistant workflow; agent loop (observe -> plan -> act -> evaluate -> learn) |
| Grounded AI | RAG diagram; context-engineering map |
| Connected entities / provenance | knowledge graph; data-lineage map |
| Safety & control | trust-boundary diagram; governance framework; guardrails stack; risk heatmap |
| Output quality | evaluation-harness diagram; model-drift chart |
| Implementation choices | model-selection matrix; build/buy/partner matrix |
| AI economics | AI economics waterfall; ROI curve |
| Degrees of delegated authority | autonomy ladder; confidence-threshold / decision-rights matrix |
| Real-time GTM | signal-to-action architecture |
| The whole program | AI operating model; transformation roadmap |

## Discipline

- One layer of abstraction per visual - don't put agents, models, and governance in a single flat picture.
- Name components in the audience's language, not vendor jargon.
- Limits: <=6 layers in a stack, <=6 nodes in an agent diagram.
- Title = the takeaway ("The advantage is the redesigned workflow, not any single tool"), not "Our AI architecture".

## Build

Render through **visual-master** `scripts/render_svg.py` (ai family) and `assets/signature/` (AI-native operating model, signal-to-action, AI maturity ladder); shortlist with `scripts/select_visual.py "<claim>" --family ai`. Related: **visual-process-maps** (workflow mechanics), **visual-gtm-market** (AI in the revenue motion), **visual-cue** (detection).
