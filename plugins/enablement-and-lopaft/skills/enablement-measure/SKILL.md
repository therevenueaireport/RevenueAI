# Enablement Measure — Program Metrics and ROI Skill

The most common enablement failure mode is measuring the wrong things. Training completion rates. Satisfaction scores. Attendance. These are activity metrics — they tell you the program ran, not whether it worked.

Real measurement answers one question: **Is the target behavior changing at the rate we designed for?**

Everything else is vanity.

This skill gives you a metrics architecture that captures leading indicators (early signals that the program is working before outcomes move) AND lagging indicators (outcome metrics that prove ROI after the fact).

This skill operates in two modes:
- **Design mode**: Build the measurement system before the program launches
- **Audit mode**: Assess whether an existing program has adequate instrumentation — and fix it if not

---

## The Four-Level Metrics Stack

The four-level training evaluation model (Reaction, Learning, Behavior, Results) is the industry standard framework. This skill extends them with leading indicators at each level — signals that tell you what's coming before the lagging metrics confirm it.

| Level | What It Measures | Lagging Indicator | Leading Indicator |
|---|---|---|---|
| 1 — Reaction | Did they engage? | Post-session satisfaction score | Attendance, completion rate, pre-work completion |
| 2 — Learning | Did knowledge transfer? | Pre/post knowledge assessment delta | Self-reported confidence shift, vocabulary usage |
| 3 — Behavior | Did behavior change? | Manager observation score, skill assessment | Practice session quality, self-assessment accuracy |
| 4 — Results | Did outcomes move? | Win rate, conversion, revenue, retention | Leading skill scores trending upward, behavior change rate |

## The Core Measurement Principle

**Never let a lagging metric be your first signal.**

If you wait for win rates to move to know whether your program worked, you've waited 10 weeks to discover a problem you could have caught in week 2. Leading indicators give you the ability to adjust mid-program — which is the difference between a learning organization and an expensive experiment.

## Quick Metrics Audit

Use this to assess whether an existing program is adequately instrumented:

**Reaction metrics:**
- [ ] Is session attendance tracked?
- [ ] Is pre-work completion tracked?
- [ ] Is there a post-session engagement score (not just satisfaction)?

**Learning metrics:**
- [ ] Was a pre-assessment administered before the program?
- [ ] Is there a post-assessment or knowledge check mid-program?
- [ ] Is learner self-reported confidence being tracked over time?

**Behavior metrics:**
- [ ] Is there a scored skill rubric being applied to real-world performance?
- [ ] Are manager observation reports being collected?
- [ ] Is self-assessment accuracy (gap between self-score and expert score) being tracked?
- [ ] Is there a trend line showing individual skill scores over time?

**Results metrics:**
- [ ] Is there a specific business outcome metric tied to this skill?
- [ ] Is there a pre-program baseline for that metric?
- [ ] Is attribution methodology established (isolating the program's contribution)?

**Scoring**: 10-12 checked = strong instrumentation. 7-9 = functional but blind spots exist. Below 7 = program is flying blind; add instrumentation before the next cycle.
