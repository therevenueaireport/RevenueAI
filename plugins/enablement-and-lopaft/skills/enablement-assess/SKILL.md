# Enablement Assess — Learner Baseline and Diagnostic Skill

The most common reason a well-designed program fails is that it was designed for the wrong learner. A curriculum built for Level 2 delivered to a room of Level 1s produces overwhelm. The same curriculum delivered to Level 3s produces disengagement and attrition.

Assessment is not overhead. It is the intelligence that makes everything else accurate.

This skill operates in two modes:
- **Design mode**: Run before building a program to establish baselines and sequence correctly
- **Audit mode**: Run against an existing program to diagnose why it is underperforming

---

## The Two Assessment Questions

Every baseline assessment answers exactly two questions:

**1. Where is this learner on the Four Levels of Competency for this specific skill?**
Not in general. Not as a person. For this skill, right now.

**2. What is the gap between where they are and where the program assumes they are?**
This gap is where most programs silently fail. They assume a starting point that doesn't match reality.

## Assessment Methods by Context

| Method | Best For | Time Required |
|---|---|---|
| Structured self-assessment survey | Large groups, async baseline | 10-15 min |
| Observed performance sample | Skills with behavioral evidence | 30-60 min |
| Manager perception survey | Cross-referencing self-report | 10 min |
| Knowledge check (pre-test) | Cognitive/conceptual skills | 15-20 min |
| Skill demonstration | High-stakes technical skills | 20-40 min |
| 1:1 diagnostic interview | Individual coaching baseline | 30 min |

## Rapid Level Classifier

When time is limited, use this to place learners quickly:

| Response to "Tell me about your experience with [skill]" | Likely Level |
|---|---|
| "What is that?" / blank stare / "I've never done that" | Level 1 |
| "I've heard of it but I'm not sure I do it right" / "I try but it doesn't always work" | Level 2 |
| "I can do it but I have to think about it / it takes effort" | Level 3 |
| "I just do it automatically / I don't really think about it anymore" | Level 4 |

Cross-reference with observed performance — self-report and actual performance frequently diverge.

---

## Audit Mode — Checklist

Use this when evaluating a program that already launched:

- [ ] Was a formal baseline assessment conducted before program launch?
- [ ] Were learners segmented by level before content was assigned?
- [ ] Does the program entry point match the documented learner level?
- [ ] Is there evidence of learner level mapping in the program design documentation?
- [ ] Were outliers (significantly above or below cohort average) identified and routed differently?
- [ ] Is there a mechanism to re-assess learners mid-program as they advance?
- [ ] Does the program account for variance within the cohort (mixed levels)?

**Scoring**: 6-7 checked = strong baseline design. 4-5 = functional but gaps exist. Below 4 = assessment was likely skipped; program-learner mismatch is probable.
