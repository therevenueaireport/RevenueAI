# COACH Methods: Manager Development Curriculum and Coaching Instruments

**Use this file when:**
- You are building manager coaching capability before a program or AI-tool rollout launches.
- Managers say they coach, reps say they do not, and outcomes are flat.
- You need a session agenda, a question bank, a feedback calibration exercise, or a rubric to score coaching quality.
- You are introducing AI call-review data and need to keep it a coaching tool, not a surveillance tool.

The SKILL.md places each manager on the Four Levels for coaching. This file develops them.

---

## 1. Core Idea: Coaching Is a Skill, So Teach It With LOPAFT

Managers learn to coach the same way reps learn to sell. A one-day "coaching workshop" is a Learn event. It moves a manager from Level 1 to Level 2 at best. The curriculum below runs every LOPAFT step on the coaching skill itself, so the manager experiences the method they will use on reps.

The working definition used throughout:

> **Coaching** is a dedicated conversation, separate from deal inspection and pipeline review, in which a manager uses evidence from real work to help a rep improve **one** skill, practices the adjustment with them, and agrees what will be different next time.

Deal reviews ask "what will happen with this deal?" Coaching asks "what will this rep do differently on every deal?" Both matter. Most managers only do the first and call it coaching.

## 2. The Seven Coaching Sub-Skills

These expand the seven traits in the SKILL.md into teachable, assessable units. The curriculum and the rubric in Section 9 are both built on them.

| # | Sub-skill | Observable behavior | Science behind it |
|---|---|---|---|
| 1 | Select one skill | Names a single skill per rep per cycle, with evidence for the choice | Sweller's cognitive load theory: working memory is limited; one change at a time can be practiced |
| 2 | Observe with precision | Cites a timestamp or quote, separates what happened from what it meant | Argyris's ladder of inference: people jump from data to conclusions without noticing |
| 3 | Diagnose the root cause | Distinguishes a knowledge gap, a skill gap, a will gap, and an environment gap | Mager and Pipe's performance analysis: "could they do it if their life depended on it?" |
| 4 | Deliver one adjustment | Gives one behavior to change, framed forward | Kluger and DeNisi's review of feedback interventions: feedback that pulls attention toward the self rather than the task can make performance worse |
| 5 | Practice in the session | Runs a short rehearsal of the adjustment before the session ends | Ericsson's deliberate practice: focused reps on a specific weakness with immediate feedback |
| 6 | Secure a commitment and follow up | Ends with a specific, dated feedforward commitment and checks it next time | Spaced repetition (Ebbinghaus's forgetting curve): reinforcement must return before the skill decays |
| 7 | Keep it safe | Rep talks more than the manager, admits mistakes, brings their own bad calls | Edmondson's psychological safety; the affective filter principle in LOPAFT's Practice step |

## 3. Manager Development Curriculum (6 Weeks + Sustain)

**Format:** one 90-minute group session per week (managers together, led by enablement or a skilled senior leader), plus 60-90 minutes of field work per week. Cohort of 4-8 managers. Each manager coaches 2 named reps throughout (their "coaching pair") so field work is real from week 4.

**Pre-work (week 0):**
- Each manager completes the quick diagnostic from the SKILL.md and records one current coaching session (with rep consent). That recording is their baseline, scored later with the rubric in Section 9.
- Each manager picks their 2 reps and one skill for each, using the selection rules in Section 7.

| Week | LOPAFT step | Coaching sub-skill focus | Group session (90 min) | Field work |
|---|---|---|---|---|
| 1 | **L, Learn** | What coaching is and is not; the session structure; one-skill rule | Session 1 below | Read the session template; list every "coaching" conversation from the last 2 weeks and label each coaching, deal review, or status |
| 2 | **O, Observe** | Observation precision; seeing good and bad coaching | Session 2 below | Observation drills on 3 rep calls; write behavior-only notes |
| 3 | **P, Practice** | Running the full session in role-play; feedback calibration | Session 3 below | One practice session with a peer manager playing the rep |
| 4 | **A, Apply** | Live coaching with real reps | Session 4 below | Run and record one real session with each of 2 reps |
| 5 | **F, Feedback** | Scoring coaching against the rubric; peer review | Session 5 below | Self-score both recordings; exchange one with a peer for scoring |
| 6 | **T, Teach** | Teaching a coaching move to a peer; leading calibration | Session 6 below | Each manager teaches one coaching move to a new manager or peer |
| 7+ | **F, Feedback (spaced)** | Sustain | Monthly 60-min calibration (Section 5) | Program leader scores 1 recorded session per manager per month, tapering as scores hold |

### Session 1 (Learn): What coaching is

| Min | Activity |
|---|---|
| 0-10 | Each manager shares their week-0 label count: how many conversations were coaching vs. deal review vs. status |
| 10-30 | Teach the definition, the seven sub-skills, and why one skill at a time (cognitive load) |
| 30-50 | Walk through the 30-minute session template (Section 4) step by step |
| 50-75 | Show a short recorded coaching session. Managers mark each phase of the template as they see it |
| 75-90 | Each manager writes the one skill they will coach for each of their 2 reps and the evidence. Peer checks: is it one skill? Is it observable? |

### Session 2 (Observe): Seeing precisely

| Min | Activity |
|---|---|
| 0-15 | Drill 1, "Behavior or judgment?" (Section 5) |
| 15-40 | Watch a 5-minute rep call clip. Each manager writes notes. Compare: who wrote behaviors with timestamps, who wrote judgments |
| 40-65 | Watch two coaching sessions on the same rep call: one good, one bad (staged by enablement). Managers score both with the coaching-quality rubric |
| 65-85 | Discuss: what did the good coach do in the first 5 minutes that the bad coach did not? |
| 85-90 | Assign field drills |

### Session 3 (Practice): Safe reps

Triads: one manager coaches, one plays the rep (with a brief describing the rep's real gap), one observes with the rubric. Rotate.

| Min | Activity |
|---|---|
| 0-10 | Feedback calibration exercise B (rate feedback statements, Section 5) |
| 10-35 | Round 1: 20-min compressed session + 5 min observer feedback |
| 35-60 | Round 2: rotate roles |
| 60-85 | Round 3: rotate roles. The "rep" brief this round is defensive, to practice safety |
| 85-90 | Each manager names one adjustment to their own coaching for week 4 |

No scores from this session go to anyone's manager. Practice is not a test.

### Session 4 (Apply): Debrief of first live sessions

| Min | Activity |
|---|---|
| 0-30 | Each manager plays a 3-minute clip from their live session: the moment they are proudest of or least sure about |
| 30-60 | Group identifies, per clip, which sub-skill was on display and one adjustment |
| 60-80 | Patterns: what broke most often live that held in practice? (Usually: the session drifts into deal review, or the manager talks for most of it) |
| 80-90 | Commitments for week 5 recordings |

### Session 5 (Feedback): Calibrated scoring

| Min | Activity |
|---|---|
| 0-40 | Feedback calibration exercise A (score one shared coaching session, Section 5) |
| 40-75 | Pairs exchange self-scored recordings. Each scores the other's session, then compares to the self-score. Discuss gaps of 2+ points |
| 75-90 | Each manager records their self-score vs. peer score per rubric row. The gap is their own calibration gap |

### Session 6 (Teach): Lock it in

| Min | Activity |
|---|---|
| 0-45 | Each manager teaches a 5-minute micro-lesson on one coaching move, using a clip from their own sessions as the example |
| 45-70 | One manager leads a calibration round on a fresh rep call (they run Exercise A, not enablement) |
| 70-90 | Re-take the quick diagnostic. Set the sustain cadence. Name which managers will be peer models for the next cohort |

**Exit criteria for the curriculum (rule of thumb):** a manager is ready to coach without close support when two consecutive recorded sessions score 3+ on every rubric row, scored by someone other than themselves.

## 4. The Coaching Session Structure (Minute by Minute)

### Standard session: 30 minutes

Requires: one clip or artifact (2-4 minutes long) chosen in advance, showing the skill being coached. One clip that worked and one that did not is ideal.

| Min | Phase | Manager does | Rep does | Output |
|---|---|---|---|---|
| 0-3 | **Open and check last commitment** | Asks what happened with last session's commitment | Reports specific instance(s) | Commitment met / partly / not met, with evidence |
| 3-8 | **Rep self-assessment** | Asks rep to self-assess the skill on recent calls before showing anything | Names what went well and what did not | Rep's own read (an awareness signal) |
| 8-15 | **Review the evidence together** | Plays the clip. Asks the rep what they notice first | Watches, comments | Shared observation, anchored to a timestamp |
| 15-19 | **Diagnose** | Asks questions to find the root cause: knowledge, skill, will, or environment | Explains what they were thinking at that moment | Agreed root cause |
| 19-21 | **One adjustment** | States or draws out one specific behavior change, framed forward | Restates it in their own words | One adjustment in the rep's words |
| 21-27 | **Practice** | Plays the buyer for the exact moment in the clip; rep runs the adjustment 2-3 times | Rehearses until it sounds natural | Rep has done it at least once correctly |
| 27-30 | **Feedforward commitment** | Asks when exactly the rep will use it next, and how both will know | Names the call(s) and the signal | Dated commitment written down by the rep |

**Talk ratio rule of thumb:** the rep should talk for more than half the session. If the manager is talking for most of it, it is a lecture.

**The deal review exit:** if the conversation turns to "what should I do on this deal," the manager says "Good question. Let's take that in the deal review on Thursday," and returns to the skill. Drift into deal review is the most common reason coaching sessions stop being coaching.

### Short session: 15 minutes (spaced reinforcement, weeks 4+)

| Min | Phase |
|---|---|
| 0-2 | Check commitment with evidence |
| 2-8 | One clip from the last week: rep self-assesses, manager confirms or adjusts |
| 8-13 | One rehearsal of the adjustment or a harder variant |
| 13-15 | Next commitment |

### Extended session: 45 minutes (first session on a new skill, or a stalled rep)

| Min | Phase |
|---|---|
| 0-5 | Open; set the purpose: one skill, why this skill, what evidence |
| 5-12 | Rep self-assessment, including what they believe good looks like |
| 12-22 | Observe: one strong example from a peer or library, then the rep's own clip. Compare side by side |
| 22-28 | Diagnose |
| 28-30 | One adjustment |
| 30-40 | Practice: 3-4 rehearsals with increasing difficulty |
| 40-45 | Commitment and the date of the next session |

### Session note template

```
COACHING SESSION NOTE
Rep: ____   Manager: ____   Date: ____   Session #: __ of this skill cycle
Skill being coached (one): ______________________
Last commitment: ____________________   Met? [ ] Yes [ ] Partly [ ] No   Evidence: ________
Rep self-assessment (their words): ______________________
Evidence reviewed: [call/artifact] at [timestamp]
What happened (behavior only): ______________________
Root cause: [ ] Knowledge  [ ] Skill  [ ] Will  [ ] Environment   Notes: ________
One adjustment (rep's words): ______________________
Practiced in session? [ ] Yes, __ reps   [ ] No (why: ____)
Commitment: will [do X] on [call/date]; we'll know by [signal]
Next session: [date]
```

### Cadence (spaced repetition schedule)

| Phase of skill cycle | Session type | Frequency (rule of thumb) |
|---|---|---|
| Weeks 1-2 | Extended, then standard | Weekly |
| Weeks 3-4 | Standard | Weekly |
| Weeks 5-8 | Short | Every 1-2 weeks |
| After skill holds on 3 consecutive scored samples | Check-in only | Monthly, then move to next skill |

The interval widens as the skill holds, the same principle as spaced repetition: return before the skill decays, and space further each time it holds.

## 5. Observation Training and Feedback Calibration Exercises

### Drill 1: Behavior or judgment? (15 minutes)

Managers label each statement B (behavior: a camera would capture it) or J (judgment: an interpretation). Then rewrite each J as a B.

| Statement | Label | Rewrite as behavior |
|---|---|---|
| "She wasn't confident on pricing" | J | "At 14:20 she said 'I think it's around 40, but I'd have to check'" |
| "He asked three open questions before demoing" | B | |
| "The buyer was clearly not interested" | J | "The buyer gave one-word answers to the last four questions" |
| "He rushed the close" | J | "He proposed next steps at 22:10, before the buyer had named a decision date" |
| "She talked too much" | J | "She spoke for 3 minutes uninterrupted after the first objection" |
| "He didn't use the AI summary" | J | "The CRM note for this call was written manually; the AI summary was not opened" |

**Pass:** a manager labels at least 5 of 6 correctly and rewrites every J with a timestamp or quote.

### Drill 2: The one moment (20 minutes)

Watch a 10-minute call clip. Each manager writes down the **one** moment (timestamp) that matters most for the skill being coached, and why. Compare. Discuss until the group agrees which moment a coach should use. Teaches selection: a coaching session uses one moment, not ten.

### Drill 3: Root-cause sort (15 minutes)

For each scenario, managers decide: knowledge, skill, will, or environment.

| Scenario | Root cause | Fix type |
|---|---|---|
| Rep does not know the pricing approval threshold | Knowledge | Learn: give the information |
| Rep knows to confirm the buying process, explains it well, freezes when the buyer pushes back | Skill | Observe + Practice |
| Rep can do it on demand in role-play, does not do it on live calls, says "it slows the call down" | Will (belief) | Show evidence it works on their own deals; Apply with a small commitment |
| Rep would do it, but the CRM stage requires a proposal date before discovery is complete | Environment | Fix the process, not the rep |
| Rep sends AI-drafted follow-ups unedited, says the tool "is usually right" | Skill (judgment) + belief | Seeded-error drill; Observe good vs. bad outputs |

The "could they do it if their life depended on it?" test from Mager and Pipe separates skill gaps (no) from will and environment gaps (yes). Coaching fixes skill gaps. It does not fix environment gaps; escalate those.

### Exercise A: Score the same session (calibration, 40 minutes)

1. All managers watch the same recorded coaching session (or rep call, when calibrating rep scoring).
2. Each scores it independently with the rubric. No discussion.
3. Reveal scores row by row. For any row with a spread of 2+ points, each manager cites the moment behind their score.
4. Agree the "anchor score" and write one sentence describing why. Add it to an anchor library.
5. Record the agreement rate.

**Pass threshold (rule of thumb):** scores within one point of the anchor on at least 80 percent of rows. Repeat monthly in the sustain phase. Rater drift is normal; calibration is a habit, not a one-time event.

### Exercise B: Rate the feedback statement (10 minutes)

Managers rate each statement 1 (weak) to 4 (strong) on: specific, behavioral, one thing, forward-looking. Then discuss.

| Feedback statement | Typical rating | Why |
|---|---|---|
| "Great call, keep it up" | 1 | Not specific, no behavior, nothing to do |
| "You need to work on discovery, objection handling, and next steps" | 1 | Three things, no behavior |
| "You were a bit passive" | 1 | Judgment about the person |
| "At 14:20 when they asked about price, you gave a number before asking about budget" | 2 | Specific and behavioral, but backward-looking with no adjustment |
| "At 14:20 when they asked about price, you gave a number. Next time, try asking what they've budgeted first. Let's practice it now" | 4 | Specific, one behavior, forward, includes practice |

Use the SBI structure (Situation, Behavior, Impact, from the Center for Creative Leadership) for the observation, then add the forward step (what to do next time, sometimes called feedforward, a term popularized by Marshall Goldsmith).

## 6. Coaching Question Banks

Questions beat statements because the rep's answer is a retrieval act, and retrieval strengthens learning (Roediger and Karpicke's work on the testing effect). Use 3-5 per session, not the whole bank.

### Opening and commitment check
- "Last time you said you'd try [X] on [call]. What happened?"
- "Where did you get a chance to use it? Where did you skip it?"
- "What made it easier or harder than you expected?"

### Self-assessment (ask before showing evidence)
- "On a scale of 1 to 4, where are you on [skill] this week? What makes it that number and not one higher?"
- "Which call this week was your best on this? Which was your worst? Why?"
- "If I played your last call for the team as an example, what would you want them to notice?"

### Observation (while reviewing the clip)
- "What do you notice?"
- "What was the buyer telling you at this moment?"
- "What were you thinking right here?"
- "What options did you have at this point?"

### Diagnosis
- "Did you know you wanted to [behavior] here, or did it not come to mind?" (knowledge vs. skill)
- "If you'd had another try at this moment, what would you have done?" (skill)
- "Is there a reason doing [behavior] doesn't feel worth it?" (will)
- "Is anything in the process, the CRM, or the tool making this harder?" (environment)

### Moving to one adjustment
- "If you could change one thing about this moment, what would it be?"
- "What would a great version of this sound like?"
- "Which part of what [peer model] does would you borrow?"

### Practice
- "Let's run it. I'll be the buyer, starting from where they said [quote]."
- "Again, and this time I'll push back harder."
- "How did that feel compared to the call?"

### Commitment
- "On which call this week will you use it?"
- "How will you know it worked?"
- "What might get in the way, and what will you do then?"

### For AI-tool coaching (judgment, not usage)
Built around three judgments a rep must make on AI output: is it true, is it right for this buyer, should we act at all.
- "Before you saved this summary, what did you check it against?"
- "Is there anything in this draft the buyer did not actually say?"
- "Would this email land with this buyer at this stage? What would you change?"
- "The tool suggested three follow-ups. Which one would you not send, and why?"
- "What context did you give the tool? What did it not know?"

### When a rep is defensive
- "What's your read on the call?" (start with their view)
- "What would you want me to know before we look at this?"
- "I picked this clip because it's a moment almost everyone finds hard. What makes it hard?"
- "What would make these sessions more useful to you?"

### Questions to avoid
| Avoid | Why | Use instead |
|---|---|---|
| "Why did you do that?" | Sounds like blame; produces justification | "What were you thinking at that moment?" |
| "Don't you think you should have...?" | A statement disguised as a question | State the observation, then ask "What do you make of it?" |
| "How do you think it went?" (only) | Too broad; gets "fine" | "Which moment would you replay if you could?" |
| Five questions in a row about different skills | Breaks the one-skill rule | Park the others in a list for the next cycle |

## 7. How to Coach One Skill at a Time

### Selecting the skill

| Rule | Detail |
|---|---|
| Evidence first | Choose from the rep's numbers and scored observations, not impressions. Stage conversion is often the clearest pointer: find the stage where this rep loses deals at a higher rate than the team |
| Upstream first | If two skills are weak, coach the one earlier in the sale. Downstream skills cannot hold when upstream ones fail |
| Highest leverage | The skill whose improvement would change the most deals this quarter |
| Within reach | Pick a skill the rep can improve with support now (Vygotsky's zone of proximal development). Skills with missing prerequisites go later |
| Rep's view included | Ask the rep what they want to work on first. If the data disagrees, coach the data and show the rep why |

### The cycle

| Rule | Detail |
|---|---|
| One skill per cycle | A cycle is typically 30 days (rule of thumb) |
| Agree the exit measure at the start | Observable, from a system you already have. Example: "Rubric A median 2+ on the last 3 scored calls, including one late-stage call" |
| Park everything else | Keep a "next cycle" list visible to both. It shows the rep the other issues are seen, not ignored |
| No movement at day 30 | The diagnosis was probably wrong. Re-diagnose; do not extend the same plan |
| Exit when it holds | Skill holds on 3 consecutive scored samples, including a hard one. Then move to the next skill and drop this one to monthly checks |

### Handling coaching drift

| Drift signal | Response |
|---|---|
| Manager raises a second skill mid-session | Note it on the parking list; return to the current skill |
| Rep asks about a different skill | "Good. Let's make that the next one. Today we're on [skill]." |
| A critical issue appears (compliance, customer risk) | Address it immediately, separately from the coaching session. Then return |
| Leadership changes the priority skill mid-cycle | Finish the current cycle if fewer than 2 weeks remain; otherwise close it with a recorded state and start the new one |

## 8. Coaching With AI Call-Review Data Without Turning It Into Surveillance

AI call review gives managers coverage they never had: analysis on every call, not the two a manager had time to hear. The same data can build trust or destroy it. The difference is in how it is used, not in the tool.

### Coaching use vs. surveillance use

| Coaching use | Surveillance use |
|---|---|
| Data routes the manager's attention to which calls to review | Data replaces the manager's review |
| Conversations reference clips; reps hear their own words | Conversations reference scores; reps hear numbers |
| Patterns across several calls trigger a conversation | A single call triggers a reprimand |
| Rep sees their own data first, or at the same time as the manager | Manager sees data the rep cannot see |
| Delivered privately | Posted publicly, ranked, or used in a leaderboard of weaknesses |
| Rep can dispute a score, and disputes are read | Scores are final |
| Used to develop the one skill in the current cycle | Used to find anything wrong on any call |
| Separate from performance management unless agreed in advance | Silently feeds performance reviews |

### Seven rules

1. **Patterns, not single calls.** A behavior should appear across several calls in a short window before it triggers coaching. The Revenue AI Report's coaching-nudges playbook uses at least three calls in two weeks. Machine feedback on one call reads as surveillance.
2. **Coach the behavior, never the score.** Scores route attention. Clips change behavior. Every coaching note should cite a timestamped clip.
3. **Private by default.** Weakness data goes in direct conversations, never in public channels. Public sharing is for good examples, anonymized or with consent.
4. **Rep access first.** Reps can see their own call data and scores. A rep who reviews their own call before the session arrives with a self-assessment, which is the best coaching material there is.
5. **Calibrate before you trust.** Compare model scores to human scores on a sample before anyone coaches from them. Drop or rewrite rubric lines where agreement is low. Consistent is not the same as correct: a model applies the wrong parts of a rubric just as consistently as the right parts.
6. **A dispute path.** One simple way for a rep to say "this score is wrong," read by a human. Disputes improve the rubric.
7. **Watch for Goodhart's law.** When a measure becomes a target, people optimize the measure. If reps learn that talk ratio is scored, talk ratio will move, and the conversation may not improve. Rotate what is emphasized and always pair a metric with a clip.

### Team data charter (agree before rollout)

```
CALL DATA COACHING CHARTER
Team: ____   Tool: ____   Agreed on: ____   Review date: ____

What we record:              [calls, with disclosure wording approved by legal]
Who can see a rep's data:    [rep, their manager, enablement. Not peers.]
What the data is used for:   [coaching the current skill; choosing calls to review]
What it is NOT used for:     [e.g., ranking reps publicly; single-call discipline;
                              performance ratings, unless separately agreed]
Coaching trigger:            [pattern threshold, e.g., 3 calls in 2 weeks]
How reps dispute a score:    [method, who reads it, response time]
What gets shared publicly:   [good examples only, with consent or anonymized]
How we check the model:      [human vs. model agreement, how often, published where]
```

Have managers and reps read and agree it together. This is readiness item M5 in `enablement-assess`.

### Manager behaviors that turn data into surveillance (and the fix)

| Behavior | Fix |
|---|---|
| Messaging a rep about a single flagged moment the same day | Batch into the next coaching session; require the pattern threshold |
| Opening a session with "your score dropped" | Open with the commitment check, then play the clip |
| Listing every flagged issue | One skill. Park the rest |
| Comparing reps by score in a team meeting | Share one good clip instead |
| Coaching from the dashboard without listening to the call | Rule: no coaching note without a clip the manager has listened to |

## 9. Manager Coaching-Quality Rubric

Score one recorded coaching session. Each row 1-4. The levels mirror the Four Levels of Competency for coaching itself.

| Row | 1. Unconscious Incompetence | 2. Conscious Incompetence | 3. Conscious Competence | 4. Unconscious Competence |
|---|---|---|---|---|
| **Focus** | No clear skill; covers whatever comes up | Names a skill but drifts to others or into deal review | Holds one skill with effort; redirects drift | One skill throughout; drift handled smoothly |
| **Evidence** | Coaches from memory or impression | References a call in general terms | Uses a specific clip or artifact with a timestamp | Evidence chosen well in advance; rep has reviewed it too |
| **Observation** | Judgments ("you were weak") | Mix of judgments and behaviors | Behavior-based, separates observation from interpretation | Precise; asks the rep to observe first and builds on it |
| **Diagnosis** | Assumes cause; jumps to a fix | Asks about cause but does not test it | Distinguishes knowledge, skill, will, environment | Finds the root cause through questions; rep reaches it themselves |
| **Feedback** | List of issues or vague praise | One area named but not a specific behavior | One specific, forward-framed adjustment | Adjustment in the rep's own words, tied to the rubric |
| **Practice** | None | Discusses what to do differently | At least one rehearsal in the session | Several rehearsals with increasing difficulty |
| **Commitment** | None | General intention ("I'll try") | Specific, dated commitment | Commitment with a signal both will check; last one followed up |
| **Safety and talk ratio** | Manager talks most; rep defensive or silent | Manager talks most; rep polite | Rep talks about half; admits mistakes | Rep talks most; brings own difficult calls |

**Scoring:**

| Total (of 32) | Read |
|---|---|
| 28-32 | Strong. Candidate peer model and Teach-step leader |
| 21-27 | Functional. Pick the lowest row as this manager's one coaching skill for the next cycle |
| 14-20 | Developing. Needs Practice-step support (triads, observed sessions) |
| 8-13 | Not yet coaching. Run the diagnosis in Section 10 before more training |

**Use the lowest row, not the total, to choose what to work on.** The manager gets coached on one skill at a time, the same as their reps.

### Rep-side pulse (4 items, anonymous, monthly)

Supports the "affective environment" rows of the SKILL.md audit.

| Item | Scale |
|---|---|
| My last coaching session focused on one specific skill | 1 (strongly disagree) to 5 (strongly agree) |
| My manager used a real example from my work | 1-5 |
| I practiced something in the session | 1-5 |
| I feel safe bringing my worst calls to coaching | 1-5 |

## 10. Diagnosing a Manager Who Is Not Coaching

Do not assume a capability gap. Training a manager who lacks time, incentive, or belief produces a trained manager who still does not coach. Use Thomas Gilbert's Behavior Engineering Model as the frame: performance depends on the environment (information, resources, incentives) as well as the individual (knowledge, capacity, motives). Check the environment first; it is cheaper to fix and more often the cause.

### Diagnostic table

| Cause | Evidence to look for | Diagnostic question | Fix |
|---|---|---|---|
| **Clarity** (does not know it is expected) | No written coaching expectation; sessions not on calendars | "What does your leader expect from you on coaching, in numbers?" | Written expectation: sessions per rep per month, format, which skill |
| **Capacity** (no time) | Calendar full of internal meetings and deal reviews; large span of control | "Walk me through last week. Where would a coaching session fit?" | Remove or shorten a recurring meeting; protect a coaching block; use the 15-minute format |
| **Incentive** (not rewarded, or rewarded for something else) | Manager's own scorecard measures only forecast and pipeline; their leader only asks about deals | "When your leader meets with you, how much of the time is about coaching?" | Add coaching activity and quality to the manager's scorecard; their leader asks about it weekly |
| **Tools and data** (no evidence to coach from) | No recordings, no rubric, cannot find clips | "Show me how you'd find a clip for [rep] right now" | Access, a rubric, a 15-minute clip-finding routine |
| **Knowledge** (does not know how) | Quick diagnostic shows Level 1-2; sessions are status updates | "Describe the last time you coached a skill." (SKILL.md diagnostic) | The 6-week curriculum |
| **Confidence** (knows how, avoids it) | Can describe good coaching; avoids difficult reps or skills they are weak at themselves | "Which reps are hardest to coach? What happens in those sessions?" | Practice triads with a defensive-rep brief; start with an easier rep |
| **Belief** (does not think it works) | "My best reps don't need it, my worst won't change"; prefers to step in on deals | "What would you need to see to believe coaching moves numbers here?" | Run one 30-day cycle with one rep and agree the measure in advance; let the result make the case |
| **Own skill gap** (cannot model the skill) | Manager scores low on the rep rubric themselves | Test with the rep rubric or seeded-error drill (`enablement-assess`, Rubric B) | Manager goes through the rep program first, or a peer manager coaches that skill |

### The diagnostic conversation (20 minutes)

| Min | Step |
|---|---|
| 0-3 | Purpose: "I want to understand what gets in the way of coaching, not grade you." |
| 3-8 | Calendar walk-through of last week |
| 8-12 | "Describe the last time you coached a skill" (SKILL.md quick diagnostic, four listening points) |
| 12-16 | Incentive and belief questions from the table |
| 16-20 | Agree the single biggest blocker and one change for the next 2 weeks, with a check date |

### Decision rules

- If capacity or incentive is the cause, **do not send the manager to training first.** Fix the environment, then train.
- If the manager's own leader does not ask about coaching, the fix belongs one level up. Coaching cascades: managers coach the way they are coached.
- If a manager has been through the curriculum, has time and incentive, and still scores 8-13 after two cycles, it is a role-fit conversation for their leader, not another workshop.
- If several managers show the same cause, it is a system problem. Fix it once for all of them.

## 11. Worked Example (Illustrative)

*All names and numbers are invented for illustration.*

**Context:** A revenue team of 5 frontline managers and 30 AEs is rolling out an AI call-review tool. The baseline from `enablement-assess` shows that late-stage deals stall because AEs propose before confirming the buying process. Manager readiness scored 4 of 10.

**Week 0 diagnosis:**

| Manager | Quick diagnostic | Recorded session score (of 32) | Main cause |
|---|---|---|---|
| A | 4 of 4 yes | 24 | Lowest row: Practice (talks through it, never rehearses) |
| B | 2 of 4 | 15 | Knowledge: sessions are deal reviews |
| C | 1 of 4 | 11 | Capacity: 9 hours a week of forecast meetings |
| D | 3 of 4 | 19 | Confidence: avoids two senior AEs |
| E | 0 of 4 | 9 | Incentive and belief: "my job is the number" |

**Actions before the curriculum:**
- Manager C: the CRO cuts one weekly forecast meeting to 30 minutes for all managers, freeing a coaching block.
- Manager E: the CRO adds "coaching sessions held" and "rep pulse score" to the manager scorecard and asks about them in every weekly 1:1. Manager E agrees to run one 30-day cycle with one AE as a test.

**Curriculum (weeks 1-6):** all five managers, each with 2 AEs. Skill for every AE in this first cycle: confirming the buying process before proposing (Rubric A in `enablement-assess`). Using the same skill across the team makes calibration easier.

**Data charter:** agreed in week 1 with reps present. Coaching trigger is the pattern threshold; no single-call messages; scores visible to the rep; disputes go to enablement.

**Week 5 calibration:** first scoring of a shared session shows managers within one point of the anchor on 60 percent of rows. The spread is on "Diagnosis": managers B and E score any question about cause as a 3. The anchor sentence is rewritten: "3 requires the manager to distinguish at least two possible causes before settling on one." Second round: 85 percent.

**Week 6:** Manager A leads the calibration round and becomes the peer model for the next cohort. Manager D teaches "starting with the rep's own read" using a clip from a session with one of the senior AEs.

**Day 30 for Manager E's test cycle:** the AE's scored late-stage calls moved from a median of 0 to a median of 2 on Rubric A. The measure was agreed in advance, so the result is not contested. Manager E asks to add the second AE.

**What the program leader reported:** "Two of five managers were not coaching for reasons training would not have fixed: calendar and scorecard. Those were fixed first. After six weeks, four of five managers score 21+ on recorded sessions, scored by someone other than themselves."

## 12. Common Mistakes

| Mistake | Why it fails | Fix |
|---|---|---|
| A one-day coaching workshop as the whole program | It is a Learn event; no Observe, Practice, or Feedback on the coaching skill | Run the full curriculum with field work |
| Calling deal reviews coaching | Deal reviews fix deals, not reps | Separate calendar block; separate note template |
| Coaching three skills at once | Cognitive overload; nothing changes | One skill per cycle; parking list |
| Coaching from the dashboard | Reps discount feedback they cannot hear | No note without a clip |
| Feedback without practice | Knowing the adjustment is not being able to do it | Rehearse in the session, every session |
| No follow-up on commitments | The forgetting curve wins | Open every session by checking the last commitment |
| Training managers who have no time | Trained managers still do not coach | Diagnose capacity and incentive first |
| Managers never observed coaching | They cannot calibrate their own sessions | Recorded sessions scored by someone else monthly |
| Public leaderboards of AI-detected weaknesses | Destroys safety and adoption | Private by default; share good examples only |
| Same cadence forever | Wastes time on held skills, under-supports new ones | Space sessions out as the skill holds |
| The manager's own leader never asks about coaching | Coaching drops to whatever gets asked about | Put coaching on the manager's scorecard and in their 1:1s |
