# Build an Account Expansion Plan

> From the [Revenue AI Report skill library](https://www.therevenueaireport.com/skills). Level: Intermediate · Task: Grow Accounts · Setup: About 30 minutes · For: Customer Success, Sales Leader, Sales Representative

**Outcome:** A plan for growing one existing account: where the whitespace is, who to reach, and the first three plays.

## When to use
- Quarterly account planning for top accounts.
- When an account is healthy but flat.

## Inputs you need
- What the account owns today and what they pay
- Org structure or teams you do and do not touch
- Their stated goals for the year, if known

## Quick prompt
Paste into any AI assistant. Replace the [bracketed] parts.

```text
You are an account strategist. Here is an existing customer: [paste what they own, usage, teams touched, goals]. Build an expansion plan: the two most credible expansion paths and why, the roles we need to reach for each, the trigger event that would make each path timely, the first three plays with owners, and the honest reason each path might fail. Base it on what they already get value from. Do not propose selling them everything.
```

## Process
1. Map what they own, use, and get value from today.
2. Generate paths. Keep only those that extend current value.
3. Assign an owner and a first step to each play.
4. Tie each path to a trigger so timing is defensible.
5. Review at the next QBR and update.

## Decision rules
- A path that does not extend existing value is a new sale, not expansion. Treat it as one.
- No trigger, no play. Wait for the timing.
- If the current deployment has open value problems, fix those before any expansion ask.

## Output
- Two expansion paths with roles, triggers, and plays.
- The failure risk for each path, stated plainly.

## Quality checks
- Each path builds on proven value.
- Each play has an owner and a first step.
- Failure risks are written down, not implied.

## Limitations
- Whitespace analysis is only as good as your org knowledge. Guessy org charts produce guessy plans.
- The AI cannot know procurement constraints or internal politics at the account.

## Worked example
**Input:** Owns sales-cloud seats for 60 reps in North America. High usage. EMEA team of 40 uses spreadsheets. Goal stated at kickoff: one forecast process globally by year end.

**Output:** Path one: EMEA rollout tied to their stated global-forecast goal; reach the EMEA sales director; trigger is their Q4 planning cycle. Path two: add the forecasting module to NA tied to the same goal. Failure risk for path one: EMEA leadership was never part of the original decision and may see this as a NA project imposed on them.

## Review checklist
- [ ] Does each path extend current value?
- [ ] Is a trigger attached to each?
- [ ] Were failure risks said out loud?
