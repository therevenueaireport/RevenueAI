# Revenue AI Report: Open Skill Library

**86 free, installable AI skills for B2B revenue teams.** Sales, marketing, RevOps, customer success, enablement and the executives who own the number.

Every skill here is a repeatable job with a ready prompt, a process, decision rules and a quality bar. Use them in Claude Code, Claude.ai, or paste the prompt into any assistant.

Built by [The Revenue AI Report](https://www.therevenueaireport.com), a weekly read on what AI actually did inside B2B revenue teams: receipts, benchmarks, post-mortems. No theory.

> **[Subscribe free at therevenueaireport.com](https://www.therevenueaireport.com)** to get new skills, prompts and playbooks before they land here.

## Install

### Claude Code (recommended)

Add the marketplace once, then install the packs you want:

```text
/plugin marketplace add therevenueaireport/RevenueAI
/plugin install coach-k-frameworks@revenue-ai-report
/plugin install revenue-ai-report-skills@revenue-ai-report
/plugin install analytics-and-decisions@revenue-ai-report
/plugin install enablement-and-lopaft@revenue-ai-report
/plugin install visual-kit@revenue-ai-report
/plugin install brand-distinctiveness@revenue-ai-report
/plugin install voice-and-content@revenue-ai-report
/plugin install skill-graph-kit@revenue-ai-report
```

### Claude.ai or Claude Desktop

Download any skill folder (the folder that holds `SKILL.md`), zip it, and upload it under **Settings > Capabilities > Skills**.

### Any other assistant

Open a skill's `SKILL.md`, copy the **Quick prompt**, and paste it into ChatGPT, Gemini, Copilot or whatever your team uses. Replace the `[bracketed]` parts.

## About

The Revenue AI Report is written for revenue leaders who are expected to grow revenue with AI instead of headcount, and need proof of what actually works. CROs, CCOs, heads of sales, marketing, RevOps, GTM engineering, enablement, partnerships and CS, plus the founders and CEOs who own revenue.

Created by **Jonathan Kvarfordt (Coach K)** of The Revenue AI Report and GTM AI Academy. LOPAFT, SCALE and OAR are his frameworks, and the Proof Gap, the Reversal Ledger, the Eight-Seat Read and Optimization Theater are concepts he coined. See them all at [therevenueaireport.com/frameworks](https://www.therevenueaireport.com/frameworks).
