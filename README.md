# Revenue AI Report: Open Skill Library

**58 free, installable AI skills for B2B revenue teams.** Sales, marketing, RevOps, customer success, enablement and the executives who own the number.

Every skill here is a repeatable job with a ready prompt, a process, decision rules and a quality bar. Use them in Claude Code, Claude.ai, or paste the prompt into any assistant.

Built by [The Revenue AI Report](https://www.therevenueaireport.com), a weekly read on what AI actually did inside B2B revenue teams: receipts, benchmarks, post-mortems. No theory.

## Install

### Claude Code (recommended)

Add the marketplace once, then install the packs you want:

```text
/plugin marketplace add therevenueaireport/RevenueAI
/plugin install revenue-ai-report-skills@revenue-ai-report
/plugin install analytics-and-decisions@revenue-ai-report
/plugin install enablement-and-lopaft@revenue-ai-report
/plugin install visual-kit@revenue-ai-report
```

### Claude.ai or Claude Desktop

Download any skill folder (the folder that holds `SKILL.md`), zip it, and upload it under **Settings > Capabilities > Skills**.

### Any other assistant

Open a skill's `SKILL.md`, copy the **Quick prompt**, and paste it into ChatGPT, Gemini, Copilot or whatever your team uses. Replace the `[bracketed]` parts.
